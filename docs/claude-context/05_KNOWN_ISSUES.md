# Problemas Conocidos

- LLM responde genérico cuando no debería
- Máquina de estados no gobierna completamente flujo
- Persistencia de estado requiere validación runtime
- Riesgo de duplicados por reintentos webhook
- Inyección de catálogo al LLM no siempre consistente

Infraestructura NO es el problema.
DB NO es el problema.
Dashboard NO es el problema.

El problema es lógico (runtime / agente).
